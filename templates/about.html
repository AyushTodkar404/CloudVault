The 5 Cloud Service Models Implemented

Full compliance with the Cloud Computing laboratory syllabus criteria

5 / 5 Delivered
PaaS Azure App Service

Platform as a Service

Hosts the Python 3.14 web application on Linux without requiring manual OS patching or web server installation. Automated CI/CD deployments trigger on every Git push via GitHub Actions.

DBaaS Azure SQL Database

Database as a Service

Fully managed relational database providing ACID transactions, automated daily backups, and point-in-time recovery for student user profiles, document metadata, and activity telemetry.

SaaS / Object Azure Blob Storage

Storage as a Service

High-durability blob container (/documents) storing physical files with unique UUID namespaces, inline streaming headers, and sub-second download access.

SECaaS Key Vault & Audit

Security as a Service

Zero-Trust identity framework utilizing Scrypt cryptographic key derivation, SHA-256 public share tokens, and tamper-evident audit logging for user logins, uploads, and deletions.

IaaS Azure Linux Virtual Machine

Infrastructure as a Service

A dedicated Ubuntu Linux Virtual Machine (cloudvault1-vm) provisioned in a private Azure Virtual Network (vnet-centralindia-1). Demonstrates full root infrastructure control, custom firewall rules (NSG), and operates as an external health sentinel polling the /health endpoint.
